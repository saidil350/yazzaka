# Public Sans + Preset shadcn `b2KtQh6AzK` di Panel CMS (scope terbatas)

**Hasil akhir yang disetujui:** seluruh font & heading di panel CMS memakai Public Sans, dan token tema penuh dari preset `b2KtQh6AzK` (font + warna + radius) diterapkan **hanya di dalam panel CMS**. Situs publik tetap Plus Jakarta Sans + Newsreader dengan brand teal/orange yang sekarang.

## Langkah implementasi

1. **Decode & aplikasikan preset untuk mendapatkan nilai token aslinya**
   - `npx shadcn@latest preset decode b2KtQh6AzK` → catat konfigurasi (font, warna, radius).
   - `npx shadcn@latest apply b2KtQh6AzK` → biarkan CLI menulis token tema ke `src/app/globals.css`, lalu **git-diff hasilnya**. Nilai token hasil apply menjadi sumber kebenaran isi preset.
   - **Re-scope:** pindahkan semua perubahan token hasil apply ke blok scope `.admin-scope { ... }` di `globals.css` (override `--color-*`, alias `--background`/`--primary`/dst., serta set variabel radius lengkap `--radius`, `--radius-sm/md/lg/xl` — variabel turunan harus didefinisikan ulang karena di-compute di `:root`). Nilai token global dikembalikan seperti semula agar situs publik tidak berubah. Catatan Tailwind v4: utilitas `bg-primary` dsb. memakai `var(--color-primary)`, jadi override di level scope otomatis dipakai semua komponen `ui/*` di dalam scope (repo memakai `@theme` biasa, bukan `@theme inline`, jadi cara ini valid).
   - Jika apply mengubah `components.json` atau file lain, review dan simpan/pulihkan sesuai konteks (preset field di `components.json` boleh dipertahankan sebagai catatan).

2. **Muat Public Sans via `next/font/google`** di `src/app/layout.tsx` mengikuti pola yang sudah ada:
   - `import { Public_Sans } from "next/font/google"` dengan `variable: "--font-public-sans"`, `subsets: ["latin"]` (variable font, tanpa weight eksplisit — pola sama dengan Newsreader).
   - Tambahkan `${publicSans.variable}` ke className `<html>` (sejajar `--font-jakarta` & `--font-newsreader`). Font dimuat global tapi hanya direferensikan di scope admin.

3. **Scope font di `globals.css`** (di `@layer base`):
   ```css
   .admin-scope {
     --font-sans: var(--font-public-sans), ui-sans-serif, system-ui, -apple-system, sans-serif;
     font-family: var(--font-sans);
     /* + token warna/radius preset dari langkah 1 */
   }
   ```
   Karena `h1–h6` tidak punya `font-family` sendiri (hanya weight/tracking di base styles), semua heading di dalam scope otomatis ikut Public Sans. Jika preset mendefinisikan token dark (`-dark`), mirror pola blok `.dark` yang ada di dalam scope juga.

4. **Pasang class `admin-scope` pada root elemen panel CMS:**
   - `src/app/admin/layout.tsx` — wrapper utama (baris 62) **dan** div loading verifikasi sesi (baris 54).
   - `src/app/login/page.tsx` — halaman login CMS (ada di luar `/admin`, tapi bagian dari pengalaman panel CMS).
   - `src/app/admin/login/page.tsx` — wrapper halaman redirect.
   - `AdminSidebar`, `AdminTopbar`, dan semua halaman admin berada di dalam wrapper ini → otomatis ter-scope. Tidak ada komponen `ui/*` yang diubah (tetap stock shadcn, sesuai aturan AGENTS.md).
   - `font-mono` di form slug/URL admin tidak diubah (stack mono fungsional, bukan bagian "font UI").

5. **Verifikasi:**
   - `npx tsc --noEmit` dan `npm run build`.
   - Browser-verify via `docs/AKUN-TESTING.md` (admin.baru@yazzakka.sch.id): login + dashboard + satu halaman settings → font Public Sans & warna preset aktif di panel; homepage publik dan satu halaman publik (mis. /berita) → tetap Jakarta + brand teal/orange, tidak berubah.
   - Screenshot sebelum/sesudah untuk perbandingan.

## Catatan
- Apply CLI berjalan global secara desain; langkah re-scope di atas adalah yang membuat hasilnya sesuai kesepakatan ("preset penuh, tapi hanya di panel CMS"). Jika kelak Anda menjalankan `shadcn apply` lagi, ia akan menulis global lagi — token scope perlu disesuaikan manual.
